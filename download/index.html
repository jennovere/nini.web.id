3 Langkah Instalasi (sekali ekstrak)

  1. Download NINI_Follower_v1.0.2_Package.zip lalu ekstrak SEKALI saja (klik kanan → Extract Here). Tidak ada zip kedua di dalamnya.
  2. Buka folder "Nini Follower v1.0.2", dobel-klik NiniCopyTrade-Follower-v1.0.2.exe. Jika SmartScreen muncul: More info → Run anyway. Jika Test Connection gagal: klik kanan EXE → Run as administrator (Anti-Blokir butuh hak admin).
  3. Di aplikasi: Settings → Aktivasi (Trial/Licensed) → tekan Play. Panduan lengkap ada di README_INSTALASI.txt di dalam paket.

Cara Setting API Key Binance

  1. Login ke akun Binance Anda lewat browser, masuk ke menu Account → API Management.
  2. Klik Create API, pilih System generated, beri label misalnya NINI-Follower, lalu selesaikan verifikasi keamanan (2FA).
  3. Pada pengaturan API tersebut: centang Enable Futures, dan pastikan Enable Withdrawals JANGAN dicentang (harus nonaktif).
  4. Disarankan aktifkan Restrict access to trusted IPs only dan isi IP publik Anda untuk keamanan maksimal.
  5. Salin API Key dan API Secret, lalu tempel di aplikasi NINI Follower pada menu Settings sebelum menekan Play.
⚠ Penting: API Secret hanya ditampilkan satu kali saat pembuatan — simpan baik-baik. Jangan pernah mengaktifkan Withdrawals dan jangan bagikan Secret ke siapa pun. Dana tetap di akun Binance Anda, aplikasi hanya mengeksekusi order futures.
