Non-Custodial & Keamanan

Dana Anda, akun Anda

  • Nini Bot bukan penitip dana Anda.
  • Dana Anda tetap di akun Binance Anda sendiri.
  • Sistem hanya menggunakan akses API untuk menjalankan fungsi trading yang Anda konfigurasi.

Yang tidak pernah kami minta

  • Kami tidak pernah meminta kata sandi Binance Anda.
  • Kami tidak pernah meminta seed phrase atau private key Anda.
  • API key dibuat dan disimpan oleh Anda, di perangkat Anda sendiri.

Atur izin API dengan hati-hati

Izin API sebaiknya Anda atur sendiri dengan hati-hati. Jika konfigurasi API Anda mengizinkan, nonaktifkan izin Penarikan (Withdrawal) dan aktifkan hanya fungsi trading yang Anda butuhkan. Membatasi key hanya untuk perangkat atau alamat IP tepercaya, sepanjang Binance mengizinkannya, menambah lapisan perlindungan.

Copy Trading

Copy trading membantu Anda mengikuti dan menyalin aktivitas trading berdasarkan strategi yang tersedia. Ketika strategi membuka atau menutup posisi, jenis trade yang sama dapat dieksekusi di akun Anda yang terhubung sesuai pengaturan Anda.

Copy trading melibatkan risiko finansial. Kinerja masa lalu tidak menjamin hasil di masa depan.

Anda memilih strategi mana yang diikuti, berapa alokasinya, dan kapan berhenti. Hasil historis dipublikasikan untuk transparansi — termasuk periode rugi — agar dapat Anda tinjau sendiri sebelum mengambil keputusan.
